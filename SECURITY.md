# Security Policy

## Supported versions

Only the latest published release of `@shipstation/shipstation-js-sdk` receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/shipstation/shipstation-js-sdk/security/advisories).

Include as much of the following as you can:

- A description of the issue and its impact.
- The affected SDK version and Node.js version.
- Steps or a minimal code sample to reproduce it.

## Scope

This policy covers the code in this repository. Vulnerabilities in the ShipStation API itself or in
ShipStation products should be reported through ShipStation's official support channels, not here.

## What to expect

We will acknowledge the report, investigate, and keep you informed of progress. Fixes are released
through the regular release process, and reporters are credited in the advisory unless they prefer
to remain anonymous.
